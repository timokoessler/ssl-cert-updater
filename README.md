# SSL Cert Updater

A tool to automatically issue Let's Encrypt wildcard SSL certificates and deploy them to multiple servers.
After the initial setup nearly any action can be done through the web UI.

> [!WARNING]  
> This software is going to be deprecated in the future. I recommend running it only behind a IP whitelist. This software was previously a internal tool of a company and the ui is only available in German.
